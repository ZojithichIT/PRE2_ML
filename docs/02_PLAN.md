# Project Plan

## Phase 1 - Problem Definition

- Define the business problem
- Define the target variable
- Identify available features
- Define evaluation metrics

## Phase 2 - Data Preparation

- Load dataset
- Inspect dataset
- Check missing values
- Check duplicated records
- Detect outliers
- Encode categorical variables
- Split data into training and testing sets

## Phase 3 - Feature Engineering

- Analyze existing features
- Create product popularity features
- Create customer-related features
- Create seasonal features

## Phase 4 - Model Selection

Test the following regression models:

1. Linear Regression
2. Decision Tree
3. Random Forest
4. Gradient Boosting

## Phase 5 - Model Training

- Train candidate models
- Tune hyperparameters
- Record parameters and results

## Phase 6 - Model Evaluation

Evaluate models using:

- MAE
- MSE
- RMSE

Select the best-performing model.

## Phase 7 - Deployment

Prepare the selected model for predicting
sales in different scenarios.
