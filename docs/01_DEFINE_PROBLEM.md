# Define Problem

## Problem Statement

An e-commerce company wants to predict product sales
to optimize inventory management and marketing strategies.

## Objective

Build a machine learning model that predicts product sales
based on product, customer, purchase history, marketing,
and seasonal information.

## Target Variable

Product Sales

## Problem Type

Supervised Learning

Regression

## Input Features

- Product information
- Customer demographics
- Purchase history
- Marketing campaign data
- Seasonal and holiday information

## Expected Output

A numerical prediction of product sales.

## Success Criteria

The model will be evaluated using:

- MAE
- MSE
- RMSE
