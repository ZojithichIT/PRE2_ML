# Exploratory Data Analysis (EDA)

## 1. Objective

The objective of EDA is to understand the structure,
quality, distribution, and relationships within the dataset
before building machine learning models.

## 2. Dataset Overview

Document:

- Number of rows
- Number of columns
- Data types
- Target variable
- Feature variables

## 3. Data Quality Analysis

Investigate:

- Missing values
- Duplicate records
- Invalid values
- Outliers

Record the findings and the actions taken.

## 4. Univariate Analysis

Analyze individual variables.

### Numerical Features

- Distribution
- Mean
- Median
- Minimum
- Maximum
- Standard deviation

### Categorical Features

- Number of unique values
- Frequency distribution
- Most common categories

## 5. Target Variable Analysis

Analyze the distribution of Product Sales.

Questions:

- Is the target normally distributed?
- Are there extreme values?
- Is the target skewed?
- What is the typical sales range?

## 6. Bivariate Analysis

Investigate relationships between features
and Product Sales.

Examples:

- Price vs Sales
- Product popularity vs Sales
- Customer purchase frequency vs Sales
- Advertising spend vs Sales
- Seasonality vs Sales

## 7. Correlation Analysis

Analyze correlations between numerical variables
and Product Sales.

Document:

- Strong correlations
- Weak correlations
- Potential multicollinearity

## 8. Visualization

Create appropriate visualizations such as:

- Histograms
- Box plots
- Scatter plots
- Bar charts
- Correlation heatmap
- Time-series plots if applicable

## 9. Key Findings

Record the important findings discovered during EDA.

Example:

- Feature X appears to have a strong relationship with sales.
- Feature Y contains a large number of missing values.
- Sales distribution is highly skewed.

## 10. Impact on Next Steps

Explain how EDA findings affect:

- Data preprocessing
- Feature engineering
- Model selection
